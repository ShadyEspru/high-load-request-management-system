# توزيع أعضاء الفريق — 6 أعضاء

## العضو 1 — قائد الفريق ومهندس المعمارية
- إدارة الخطة الأسبوعية
- تثبيت القرارات المعمارية
- مراجعة التكامل بين المكونات
- C4 وDeployment وSystem Context
- متابعة المستودع وطلبات الدمج

## العضو 2 — Backend وواجهات API
- API Gateway
- استقبال الطلبات والتحقق منها
- Request Status API
- OpenAPI
- اختبارات التكامل للـAPI

## العضو 3 — RabbitMQ وWorker Runtime
- Exchanges وQueues وBindings
- Worker Service
- ACK/NACK وPrefetch
- Retry وDLQ
- اختبارات تعطل Worker

## العضو 4 — البيانات والاعتمادية
- PostgreSQL وتصميم الجداول
- Redis وIdempotency
- حالات الطلب وسجل الأحداث
- Flyway
- اختبارات التزامن ومنع التكرار

## العضو 5 — المراقبة واختبارات الحمل والبنية التحتية
- Docker Compose
- Prometheus وGrafana
- مؤشرات الأداء
- k6 وسيناريوهات الضغط
- جمع النتائج والرسوم البيانية

## العضو 6 — التطبيق التجريبي والتوثيق
- Android Demo
- شاشة إرسال الطلب ومتابعته
- توثيق التقرير
- Use Cases وActivity وSequence بالتنسيق مع الفريق
- دليل المستخدم وتجهيز العرض

## مسؤولية مشتركة
