# مخططات تدفق البيانات لنظام HLRMS

يحتوي هذا المجلد على مخططات تدفق البيانات  
**Data Flow Diagrams (DFD)** الخاصة بنظام إدارة الطلبات عالية الحمل.

## 1. المستوى صفر - Level 0

الملفات:

- `dfd-level0-context.drawio`
- `dfd-level0-context.png`
- `dfd-level0-context.pdf`

يعرض النظام بوصفه عملية واحدة، ويوضح تدفقات البيانات مع:

- النظام العميل
- مسؤول النظام
- منصة المراقبة
- مزوّد الهوية

لا يعرض هذا المستوى الخدمات الداخلية أو قواعد البيانات.

## 2. المستوى الأول - Level 1

الملفات:

- `dfd-level1.drawio`
- `dfd-level1.png`
- `dfd-level1.pdf`

يقسم النظام إلى العمليات التالية:

- `1.0` استقبال الطلب والتحقق
- `2.0` إدارة دورة حياة الطلب
- `3.0` النشر وإدارة الطوابير
- `4.0` معالجة الطلب
- `5.0` إدارة Retry وDLQ
- `6.0` الاستعلام والمراقبة

كما يوضح مخازن البيانات:

- `D1` قاعدة بيانات الطلبات
- `D2` سجل الحالات والمحاولات
- `D3` مخزن إعدادات Retry

## قاموس البيانات

يشرح ملف `DATA-DICTIONARY.md` محتوى تدفقات البيانات الأساسية، مثل:

- Request Payload
- Validated Request
- Queued Message
- Failure Metadata
- Retry Message
- Metrics and Health Data

## ملاحظات منهجية

1. يوضح DFD حركة البيانات ولا يوضح تسلسل الزمن مثل Sequence Diagram.
2. لا تمثل العمليات Classes أو Services حرفية، بل وظائف منطقية.
3. لا يظهر RabbitMQ كمخزن بيانات تقليدي، بل ضمن عملية النشر وإدارة الطوابير.
4. يجب أن تتوازن تدفقات Level 0 مع Level 1؛ أي لا تُضاف جهة خارجية جديدة دون ظهورها في المخطط الأعلى.
