# System Context Diagram

يمثل هذا المخطط حدود نظام HLRMS وعلاقاته مع الأطراف والأنظمة الخارجية فقط.

## الملفات

- `system-context.drawio`: الملف القابل للتحرير باستخدام Draw.io.
- `system-context.png`: نسخة مناسبة للتقرير والعرض.
- `system-context.pdf`: نسخة عالية الجودة للطباعة والتسليم.

## قاعدة التعديل

تُجرى التعديلات دائمًا على ملف `.drawio` ثم يعاد تصدير PNG وPDF.
لا تُضاف المكونات الداخلية مثل RabbitMQ وWorkers وPostgreSQL إلى هذا المخطط؛ تظهر لاحقًا في مخطط C4 Container والمخططات التفصيلية.
