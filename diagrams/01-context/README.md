# System Context Diagram

## الهدف
إظهار حدود النظام والجهات الخارجية التي تتفاعل معه، دون إظهار RabbitMQ أو قاعدة البيانات أو الخدمات الداخلية؛ فهي تفاصيل تظهر لاحقًا في Container وComponent Diagrams.

## العناصر
- الأنظمة العميلة: ترسل الطلبات وتستعلم عن حالتها.
- HLRMS: النظام موضوع الدراسة.
- مسؤول/مشغل النظام: المراقبة والإدارة وإعادة تشغيل الرسائل الفاشلة.
- الخدمات الخارجية: خدمات قد ينفذ Worker عمليات باتجاهها.
- منظومة المراقبة: تجمع مؤشرات النظام وتعرضها.

## العلاقات
- طلبات وحالات بين العملاء والمنصة.
- أوامر تشغيل ومراقبة بين المسؤول والمنصة.
- تنفيذ ونتائج بين المنصة والخدمات الخارجية.
- Metrics من المنصة إلى نظام المراقبة ولوحات للمسؤول.
